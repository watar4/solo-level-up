# 03. 新戦闘システム仕様 『ダラリア大陸』バトル v2

> 現行 ATB(`DailyBossPanel.tsx` + `boss.ts`)を土台に、**「戦う理由」「意思決定」「1年の歯応え」**を足す。
> UI は `04-battle-ui.md`、敵個体は `06-boss-design.md`、型と実装は `07-implementation.md` を参照。

---

## 1. コアループ:戦意システム(最重要変更)

**戦闘は無料ではなくなる。習慣が戦闘の燃料になる。**

```
習慣クエストをこなす ──▶ 戦意ゲージ +1 ──▶ 戦意を消費して出撃 ──▶ 物語が進む
     ▲                                                    │
     └──────── 「続きが見たいから明日も習慣をやる」 ◀────────┘
```

| 項目 | 仕様 |
|---|---|
| 戦意(Will) | ストック上限 **3**。0 なら出撃不可 |
| 獲得 | デイリークエスト完了 **1件につき +1**(1日の獲得上限 **3**)。週次クエスト完了は +2 |
| 消費 | 雑魚戦(探索)= **1** / 中ボス戦 = **1** / 幹部戦 = **2** / 無限回廊 = 1 |
| 敗北時 | 戦意は**返還しない**(挑む前の準備を促す)。ただし幹部戦は初回敗北のみ 1 返還(理不尽感の緩和) |
| 廃止するもの | 現行の「いつでも無料で無限に挑める」仕様 |

- 1日にできる戦闘は最大3〜4回。**章クリアに必要な戦闘数(雑魚6〜9+中ボス1+幹部1 ≒ 戦意10〜12)× 勝率を織り込むと、章あたり最短でも4〜6日、レベル・継続ゲート込みで約1ヶ月**になる(§8)。
- クエストを1件もやらない日は戦えない。**「バトルをしようと思えない」の逆転**――バトルをしたいから習慣をやる。

## 2. 進行構造:ワールドマップと領地

- タワー(フロア連番)を廃し、**大陸マップ → 章の地方 → ノード進行**にする(ポケモンのマップ/バッジ進行の翻案)。
- 各地方は 8〜11 ノードの一本道+分岐1〜2(寄り道ノードは宝箱・小ネタ会話・衣装)。

```
[入口]─[探索1]─[探索2]─┬─[寄り道:宝]─┐
                        └─[探索3]───[中ボス]──[イベント]──[幹部]
```

- ノード種別:`battle`(雑魚)/ `elite`(中ボス)/ `lord`(幹部)/ `event`(会話)/ `treasure` / `rest`(1回だけHP全快)。
- クリア済みノードは再訪可(雑魚の再戦=素材・ゴールド稼ぎ。ただし戦意は消費)。

- 現行 ATB(速度 `6 + AGI×0.35`、目標100、50ms tick)は**そのまま採用**。実装は UI から切り離した純粋エンジンに抽出する(`07` §3)。
- **新コマンド体系(5+1):**

| コマンド | 効果 |
|---|---|
| たたかう | 通常攻撃。奥義ゲージ +10 |
| スキル | 装備スキル(最大5)。CD制は現行踏襲(`battleSkills.ts`) |
| ぼうぎょ | 被ダメ 45% カット+次手番まで状態異常耐性+30%。**チャージ技への回答** |
| どうぐ | 現行踏襲(`economy.ts:74`) |
| さくせん | 影への指示切替(§6)。手番を消費しない |
| **奥義** | 奥義ゲージ100で解放(§7)。職業固有 |

## 4. 属性:五行相性『剛・迅・魔・守・心』

現行の「ステータス=属性」(`boss.ts:214` の weak/resist)を**明示的な5属性サイクル**に昇格する。

```
剛(STR)─強→ 迅(AGI)─強→ 心(PER)─強→ 魔(INT)─強→ 守(VIT)─強→ 剛 …(循環)
```

- 弱点 ×1.5 / 耐性 ×0.6 / 等倍 ×1.0(現行係数を踏襲)。
- スキル・武器・敵すべてに属性を付与。**敵の属性はスプライトの主色で直感的に分かる**ようにする(剛=赤 / 迅=緑 / 魔=紫 / 守=黄 / 心=青。`06` §2)。
- 相性サイクルはワールドマップの凡例と図鑑(`DexPanel`)に常設表示。

## 5. ブレイクシステム(戦闘の山場を作る)

- 敵に **ブレイクゲージ**(シールド値、ボス格ほど高い)を持たせる。
- **弱点属性ヒット時のみ** ゲージが削れる(通常 -1、弱点特化スキル -2)。
- ゲージ 0 で **ブレイク**:敵は次の自ターンを失い、被ダメ ×1.5、崩れモーション+画面演出。数ターン後に復帰しゲージ再生。
- チャージ技(§下)の**キャンセル手段**でもある:溜め中にブレイクすれば不発。

**敵の行動パターン(単発攻撃からの脱却):**

| 行動タイプ | 内容 |
|---|---|
| `attack` | 通常攻撃(現行) |
| `charge → unleash` | 1ターン溜めて大技。**溜め中は頭上に「!」表示** → ぼうぎょ or ブレイクで対処 |
| `debuff` / `buff` | 攻撃力・防御・速度の増減(2〜4ターン) |
| `status` | 状態異常付与(§下) |
| `summon` | 取り巻き召喚(幹部格のみ、最大2体) |
| `gimmick` | ボス固有ギミック(`06` のロスター表参照。例:ミッカボーズの3ターンリセット) |

行動はスクリプト(重み+条件付きのパターン配列)で定義する。型は `07` §2 の `BossBehavior`。

**状態異常(6種で開始。増やしすぎない):**

| 異常 | 効果 | 治療 |
|---|---|---|
| どく | 毎手番 最大HP5%ダメ(3T) | 解毒剤/回復スキル |
| やけど | 毎手番3%+攻撃-15%(3T) | 同上 |
| ねむり | 手番スキップ。被弾で解除 | 被弾/目覚まし鐘 |
| まひ | 25%で手番スキップ(3T) | 自然回復 |
| しるし(刻印) | 被ダメ+20%。**リセット無効**(8章対策の攻略鍵) | 敵専用ではなく味方も使える |
| シールド | ダメ無効1回(敵味方共通のバフ枠) | 殴って剥がす |

## 6. パーティ:影の軍団の「さくせん」

- 影3体編成・独立ATB・自動行動(`DailyBossPanel.tsx:314` / `shadows.ts:160`)は続投。
- 追加:**作戦指示**(FFの「ガンビット」の超簡略版。戦闘中いつでも切替可、手番消費なし)

| 作戦 | 挙動 |
|---|---|
| ガンガンいこうぜ | 常に攻撃(現行挙動) |
| いのちだいじに | 味方HP50%未満なら回復系影が回復、それ以外は攻撃 |

## 7. 奥義(職業固有の必殺技)

- **奥義ゲージ**:与ダメ +10 / 被ダメ +15 / ぼうぎょ +5 で蓄積、100 で発動可。戦闘開始時 0。
- 発動時はカットイン演出(`04` §4)。職業ごとに1種+上位職で強化(`05` §3)。

| 職業 | 奥義(初期) | 効果 |
|---|---|---|
| 剣士 | 剛剣・一文字 | 剛属性 特大ダメ+ブレイク-2 |
| 魔導師 | 星霜の詠唱 | 魔属性 大ダメ+2T後にもう一度発動(遅延爆発) |
| 狩人 | 追い風の連矢 | 迅属性 中ダメ×3+自軍ATB+30 |
| 斥候 | 影縫い | 心属性 中ダメ+まひ付与+敵チャージ解除 |

## 8. バランス数理:「1年でクリア」の裏付け

### 8-1. 想定プレイモデル

- デイリークエスト 3〜4件/日、難易度は C〜B 中心、ストリーク補正(`streakMultiplier`、上限2倍)込みで
  **1日あたり EXP ≒ 600〜900(平均 750)**。

### 8-2. レベル曲線の改定(必須)

現行 `expForLevel(L) = floor(60 × L^1.55 + 40)`(`leveling.ts:5`)は Lv60 到達に累計約 77万 EXP を要し、**平均 750/日では約2.8年かかる**。以下に改定する:

```
expForLevel(L) = floor(45 × L^1.40 + 55)     // Lv L → L+1 の必要EXP
```

- Lv60 到達の累計 ≒ **約 34万 EXP** → 750/日で **約 450日 ≒ 1年+α**。継続ゲート(`02` §6)と併せて「順調な人で12ヶ月、ゆっくりで15ヶ月」のクリアレンジに収まる。
- `totalExp` 単一情報源+逆算方式(`leveling.ts:51`)のおかげで、**曲線変更は既存ユーザーのデータを壊さない**(同じ totalExp から新曲線でレベルを再計算するだけ。レベルは上振れするので体験上も損がない)。
- ランク到達(`rankForLevel`)は据え置きで整合する(Lv50=S が11章前後に来る)。

### 8-3. 敵の強さの基準線

フロア係数(`scaledBossHp` の floor 依存項)を廃し、**章ごとの想定プレイヤーレベルに対して設計値を直接置く**:

| 敵格 | HP 目安 | 撃破想定ターン | 敗北率設計 |
|---|---|---|---|
| 雑魚 | 想定Lv時プレイヤー総火力 3〜4T分 | 3〜4 | ほぼ0(テンポ重視) |
| 中ボス | 8〜10T分+ブレイクゲージ中 | 8〜12 | 初見2〜3割 |
| 幹部 | 15〜20T分+ゲージ大+ギミック | 15〜25 | **初見5〜6割**(2〜4回の再挑戦=数日がかりを意図) |

- 幹部に**適正レベル表示**(「推奨 Lv14」)をマップに出す。ポケモンのジム難度表示に相当。
- 負け→クエストでレベルと戦意を蓄える→再挑戦、が章内の基本リズム。

### 8-4. 報酬(現行から変更する点のみ)

| 報酬 | 変更 |
|---|---|
| プレイヤーEXP | **引き続き戦闘では入らない**(物語上の理由づけ済み、`02` §1)。例外として**幹部初回撃破のみ「討伐録ボーナス」**として当該章想定EXPの約1日分を付与(クリアの快感補強) |
| ゴールド | 現行式を敵格別テーブルに置換(雑魚15-40 / 中ボス120 / 幹部400、章数で漸増) |
| 影抽出 | 現行3回ロール(`boss.ts:335`)を中ボス・幹部戦のみに(雑魚は1回)。**章の新登場ダラモン=新影テンプレ**として収集欲を作る |
| 宝箱 | 現行踏襲+**衣装ドロップ**を追加(`05` §5) |
| メダル | 幹部撃破で確定。メダル1枚につき**恒久パッシブ**(例:〈はやおき〉=朝のクエストのEXP+5%)を付け、物語進行が育成にも効くようにする |

## 9. 難易度救済(詰み防止)

- 幹部に**3回敗北すると「おやっさんの助言」**(弱点・ギミック攻略のヒント会話)が自動発火。
- 5回敗北で「加勢」オプション(バルガスが1戦だけ NPC 参戦、報酬の宝箱なし)。**プライドに配慮して任意**。
- 章想定レベルを大幅超過(+8以上)している場合、雑魚戦にスキップチケット(戦意1で報酬だけ受け取る)を出し、作業感を除去。
