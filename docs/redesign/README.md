## 提案のコア思想(3行で)

1. **「習慣をこなす → 戦う権利(戦意)を得る → 物語が進む」** の一方通行ループにする。戦闘が習慣の"ご褒美"になり、習慣が戦闘の"燃料"になる。
2. **敵はすべて「悪習慣の化身」=ゆるモンスター『ダラモン』**。先延ばし、夜更かし、暴食、スマホ依存……プレイヤーが現実で倒すべきものを、ゲーム内で文字通り(でも憎めない相手として)倒す。
3. **クリアまで約1年**。章の解放条件をレベルだけでなく「継続日数・累計達成数」に紐づけることで、課金もチートもできない"リアルタイム歯止め"として機能させる。

## 既存機能との関係(壊さないもの)

- 影の軍団・抽出・進化(`src/lib/shadows.ts`, `shadowGrowth.ts`)は**そのまま活かし**、戦闘の作戦指示を追加するのみ。
- 現行の無限タワー(連続モード)は**「無限回廊」としてクリア後コンテンツに転生**させる。既存の `bossesDefeated` は移行処理で章進行に換算(`07-implementation.md` §6)。
- 食事・貯金・体重・フォーカスゲートの各タブは、章の解放条件・章テーマとして物語に**編入**する(例:第4章=暴食の章は食事記録が鍵)。
