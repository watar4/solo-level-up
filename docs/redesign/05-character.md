# 05. キャラクリ v2 ― 「選ぶ楽しさ」と「育てて変わる楽しさ」

> 現状:名前+クラス+色2つだけ。クラスは見た目のみで機械的効果ゼロ(`01-analysis.md` §2)。
> 方針:**①作成時の選択肢を増やす ②選択に意味を持たせる ③成長で見た目とビルドが変わる ④集める楽しみ(衣装)**。

---

## 1. 新キャラクリフロー(4ステップウィザード)

現行 `CharacterCreation.tsx` を置き換える。1画面ずつ、戻れる。

```
STEP1 みため → STEP2 しょくぎょう → STEP3 しんじょう → STEP4 なまえ・確認
```

### STEP1 みため(パーツ式アバター)

16×16 固定グリッド(`playerSprites.ts:173`)を廃止し、**レイヤー合成式**にする:

| レイヤー | 初期選択肢 | 備考 |
|---|---|---|
| 体型・肌色 | 肌色6 | ベース |
| 髪型 | 8種 × 髪色12 | 前髪・後髪一体で1パーツ |
| 目 | 6種 × 色8 | |
| 服(初期服) | 職業ごとの初期衣装(色替え可:主色+差し色は現行踏襲) | |
| アクセサリ | なし/メガネ/リボン/傷あと 等6種 | |

- 解像度は **24×24 に拡張**(16×16 だと髪型の差が出ない。`PixelArt.tsx` はグリッドサイズ可変なので対応は軽い)。
- プレビューは常時中央に大きく表示し、タップで「歩き/構え/勝利ポーズ」の3モーション切替(2フレームアニメ)。**触って楽しい**を最優先。
- ランダムボタン(サイコロ)を置く。迷う人の救済+遊び。

### STEP2 しょくぎょう(ついに意味を持つ)

現行4職(`types.ts:40`)を続投し、**機械的差別化**を与える:

| 職業 | 成長ボーナス(Lvアップ毎に自動+1) | 固有パッシブ | 奥義(`03` §7) |
|---|---|---|---|
| 剣士(knight) | STR, VIT | 被ダメ-8% | 剛剣・一文字 |
| 魔導師(mage) | INT, PER | スキルCD-1 | 星霜の詠唱 |
| 狩人(hunter) | AGI, PER | ATB速度+8% | 追い風の連矢 |
| 斥候(scout) | AGI, INT | 先制時ブレイク+1 | 影縫い |

- 選択画面には**五角形レーダーチャート**(成長傾向)+奥義のプレビューGIF的アニメを出す。
- 手動振り分け5pt/Lv(現行、`leveling.ts:44`)は継続。職業ボーナスは「上乗せ」なので、既存ユーザーへの遡及付与も安全(`07` §6)。

### STEP3 しんじょう(ポケモンの「せいかく」に相当)

プレイスタイル宣言。**小さなパッシブ**がつく。あとから変更可(ギルドで「座右の銘を変える」演出、無料・週1回)。

| しんじょう | 効果 |
|---|---|
| 朝型 | 午前中のクエスト完了EXP+10% |
| 夜型 | 18時以降のクエスト完了EXP+10% |
| コツコツ | ストリーク補正の上限 2.0→2.2倍 |
| 一点突破 | 週次クエストのEXP+20% |
| 収集家 | 影抽出の成功率+5% |
| 倹約家 | ショップ購入額-8% |

- 効果は小さく保つ(選び直し自由なので「正解探し」にさせない)。**自分の生活リズムを自己申告する**ことがオンボーディングを兼ねる。

### STEP4 なまえ・確認

- 名前+完成アバターのお披露目。アリア「登録完了です。評価:E。……伸びしろは、あります」(1章冒頭へ接続)。

## 2. 転職(上位職)― 育てて見た目が変わる

- **Lv20 で二次職、Lv40 で三次職**。各職2分岐(計 4→8→16 ルート)。転職は無料、分岐は排他(戻せないが、周回要素にしない=ステ再配分は既存リファンドで可)。

| 初期職 | 二次職(Lv20) | 三次職(Lv40) |
|---|---|---|
| 剣士 | ナイト(守り)/ バーサーカー(攻め) | パラディン・ロード / 剣鬼・竜殺し |
| 魔導師 | ウィザード(火力)/ セージ(支援) | 大魔導 / 賢者 |
| 狩人 | スナイパー(単発)/ レンジャー(手数) | 鷹の目 / 疾風の射手 |
| 斥候 | アサシン(妨害)/ トリックスター(搦め手) | 影番 / 千の顔 |

- 転職で:**スプライトの衣装が進化**+固有パッシブ強化+奥義が上位版に+職業スキル1個解放。
- 既存のバトルスキル15種(`battleSkills.ts`)は「共通スキル」として残し、**職業スキル(各分岐2〜3種)を追加**する形で吸収。装備枠5は据え置き。

## 3. 衣装(コーデ)システム ― 集める楽しみ

- 装備(武器=性能)とは別に、**見た目専用の「衣装」スロット**(服・帽子・アクセ)を追加。性能に影響しない。
- 入手経路:章クリア報酬(その章テーマの衣装:1章=パジャマ、4章=コック帽…)/ 宝箱ドロップ / ショップ(メルルの新作)/ 実績報酬 / 無限回廊の深層限定。
- `AppearanceEditor.tsx` を「クローゼット」画面に改装:所持衣装一覧+着せ替えプレビュー+髪型・髪色の変更(作成後も可)。
- **図鑑コンプ系のご褒美**:例)ダラモン図鑑50%で「ダラモン耳」、幹部全改心で「魔王のねまき」。

## 4. ホーム画面での露出(作った顔を毎日見せる)

- Dashboard 上部 HUD のアバターを 24×24 新スプライトに差し替え、**タップで勝利ポーズ**などの小芸を入れる。
- ステータス画面(`StatusPanel.tsx`)に全身表示+称号+メダルケース(`04` §7 `MedalCase`)を並べ、「マイキャラのページ」感を出す。

## 5. スプライト実装規格

- プレイヤー 24×24、レイヤー合成(体→服→目→髪→アクセ→武器)。各レイヤーは現行 `BossSprite` と同じ「文字グリッド+パレット」形式で資産化(`06` §2 と共通規格)。
- パレットは職業色に依存させず、**髪色・主色・差し色の3変数**を流し込む(現行 P/A 方式の拡張)。
- モーションは idle/歩き/構え/勝利/被弾 の5種 × 2フレームで十分(戦闘の juice は `04` §4 のエフェクト側で盛る)。
