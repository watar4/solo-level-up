# 04. 戦闘UI・ワールドマップUI・会話UI 設計

> 現行の「Dashboard 内モーダル」(`Dashboard.tsx:607` 付近 → `DailyBossPanel.tsx`)をやめ、
> **戦闘・マップ・会話は全画面の専用シーン**にする。モバイルファースト(既存方針踏襲)。
> 見た目のトーンは既存の `sys-*` システムウィンドウ+ドット絵を維持しつつ、章ごとの背景色で「旅してる感」を出す。

---

## 1. 画面遷移(シーン構造)

```
Dashboard(クエスト等のタブ)
   └─ [ぼうけんタブ] ──▶ WorldMap(大陸全体図)
                            └─ 章を選択 ──▶ RegionMap(地方のノードマップ)
                                              ├─ eventノード ──▶ StoryDialog(会話シーン)
                                              └─ battle/elite/lordノード ──▶ BattleScene(全画面戦闘)
                                                                                └─ 勝利 ──▶ ResultScreen ──▶ RegionMap
```

- 既存タブバー(`TabBar.tsx`)の `combat` タブを **`adventure`(ぼうけん)** に改名。中身を WorldMap への入口にする。
- シーンは `App.tsx` のトップレベル state(既存の条件分岐レンダリングの延長)で切り替え。URL ルーター導入は不要。
- 戦闘中はタブバーを隠して没入させる(逃走 or 決着でのみ復帰)。

## 2. WorldMap(大陸全体図)

```
┌─────────────────────────────┐
│  ダラリア大陸        メダル 🏅×4  │
│                              │
│   [1おはよう平原✓]─[2あしたやる沼✓]  │
│        │                      │
│   [3ピコピコ峡谷✓]─[4たべすぎ市場✓] │
│        │                      │
│   [5つかいすぎ廃坑]← いまここ      │
│   [6うごかず山🔒 Lv24/ストリーク14] │
│   ...                        │
│        [グーたら城🔒 メダル11枚]    │
├─────────────────────────────┤
│ 戦意 ⚡⚡⚡ │ Lv18 │ 累計クエスト96 │
└─────────────────────────────┘
```

- 章ノードは 3状態:**クリア済(✓とメダル表示)/ 挑戦中 / ロック(解放条件をそのまま表示)**。
- ロック中の章をタップすると、条件までの残り(「あと:ストリーク3日」)を出す。**次にやるべき習慣がここで見える**のが狙い。
- 下部に戦意ゲージを常設(現在値/上限、次の+1までに必要なクエスト数)。

## 3. RegionMap(地方のノードマップ)

- 縦スクロールの一本道+分岐(`03` §2)。ノードは丸アイコン、現在地にプレイヤーのドット絵が立つ。
- 幹部ノードには**推奨Lv表示+ボスのシルエット**(未遭遇時。遭遇後は実スプライト)。
- クリア済ノードの再訪(雑魚再戦・rest 使用済み表示)対応。

## 4. BattleScene(全画面戦闘)― 本丸

```
┌─────────────────────────────┐
│ 《章ごとの背景:平原/沼/峡谷…》     │  ← 章テーマ色のグラデ+ドット装飾2〜3種
│                              │
│      [ボス 32×32 ×4倍表示]      │  ← idle 2フレームでゆらゆら
│   クイシンボア     Lv14 ⭐弱:迅    │
│   HP ▓▓▓▓▓▓▓▓░░░░  ブレイク ◆◆◇◇ │
│   状態: [どく][攻↑]  ⚠(チャージ中!) │
├─────────────────────────────┤
│  ▶ しっぽの いちげき!  86 ダメージ!  │  ← ログティッカー(2行、かな書き)
├─────────────────────────────┤
│ [主人公]  HP▓▓▓▓░ ATB▓▓▓░ 奥義▓░░ │
│ [影A] [影B] [影C]  (小型HP/ATBバー) │
├─────────────────────────────┤
│ ┌たたかう┐┌スキル┐┌ぼうぎょ┐        │  ← DQ風コマンドウィンドウ
│ └どうぐ─┘└さくせん┘└にげる┘        │     (手番が来たときだけ点灯)
└─────────────────────────────┘
```

### 必須の演出(「juice」リスト)

| 演出 | 仕様 |
|---|---|
| ボス登場 | 暗転 → シルエット → 名前プレート「――大蛇の クイシンボア――」→ ひとことセリフ |
| ダメージ | 数字ポップ(弱点=大きく色つき+「こうかばつぐん!」、クリ=震え)。被弾側スプライトが白フラッシュ+ノックバック |
| 画面シェイク | 大技・クリティカルのみ(多用しない) |
| チャージ予告 | ボス頭上に「!」+輪郭が発光。ログ「ちからを ためている!」 |
| ブレイク | ゲージ砕けエフェクト+「くずれた!」+ボススプライトが傾く |
| フェーズ変化 | HP50%等で一時停止 → セリフ1行 → パレット差し替え(`06` §3) |
| 奥義 | 画面暗転+キャラのドット絵カットイン(横切り)+技名表示 |
| 勝利 | ボスが「改心」モーション(倒れない。座り込む→照れる)→ ResultScreen |
| 敗北 | 説教しない。アリア「……次、行きましょうか」+戦意・ヒント表示 |

- 実装は Framer Motion(既存依存)+ CSS keyframes。50ms tick の ATB 進行(現行踏襲)と演出キュー(ログ→アニメ→次の手番)を分離すること(`07` §3 のエンジン設計)。
- 偽通知ギミック(3章)・UI侵食(12章)など**UIそのものを使う演出**があるため、BattleScene は「演出レイヤー(最前面 overlay)」を最初から持たせておく。

## 5. ResultScreen(勝利画面)

- 順番に出す:ゴールド → 影抽出ロール(ドラムロール演出、現行 `rollExtraction` 流用)→ 宝箱 → (幹部なら)メダル獲得の大ゴマ+パッシブ効果の説明 → 「章クリア!住民のその後」1枚絵(ドット絵ヴィネット)。
- 幹部初回撃破時は討伐録ボーナスEXP(`03` §8-4)をレベルバー演出つきで。

## 6. StoryDialog(会話シーン)

```
┌─────────────────────────────┐
│ 《背景:地方のテーマ色》            │
│   [相手のドット絵 拡大]            │
├─────────────────────────────┤
│ アシタバケ                     │
│ 「あしたのほうが ほんき だせるって〜」 │
│                        ▼      │
└─────────────────────────────┘
```

- ドラクエ式:下部ウィンドウ+タップ送り+ページ末の「▼」。名前欄+ドット絵の拡大表示のみ(立ち絵は描かない。工数削減とトーン統一)。
- アリアのセリフだけは既存のシステムウィンドウ様式(`SystemWindow.tsx`)で出す=「システムの声」の差別化。
- スキップ可(既読・未読とも)。会話データ構造は `07` §2。
